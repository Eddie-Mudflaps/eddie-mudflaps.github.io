Privacy Policy — rclone-backup

Effective October 24, 2026

rclone-backup is a private, single-user tool. It connects the open-source rclone utility to the owner's own Google Drive account so the owner can back up files from their own storage devices. It is not offered to the public.

What data the app accesses

With the owner's permission, the app accesses the owner's Google Drive (scope https://www.googleapis.com/auth/drive) to list files, read file checksums, and upload, copy, or organise the owner's own files.

How the data is used

Data is used only to perform backups and avoid duplicate uploads, at the owner's direction. Nothing is used for advertising, profiling, analytics, or any other purpose.

Storage and sharing

The app runs entirely on the owner's own computer. No data is sent to the app developer or any third party; files move only between the owner's devices and the owner's Google account. Google authorization tokens are stored only in the local rclone configuration file on the owner's computer. No data is sold, shared, or transferred to anyone.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
